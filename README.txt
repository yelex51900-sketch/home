NAGOMI なごみ建築工房 — 実装パッケージ

■ 開き方
ZIPを展開して index.html をブラウザで開いてください。サーバーは不要です。

■ ページ
- index.html          トップ画面
- works.html          施工事例（6つのカードを押すと詳細ダイアログを表示）
- homebuilding.html   家づくり
- recruit.html        採用情報（職種カードから該当職種を選んだお問い合わせページへ）
- company.html        会社案内（アクセス地図を押すとGoogleマップで地域検索）
- contact.html        お問い合わせフォーム

■ デザインについて
提供されたNAGOMIの5枚のPNG（1366×768）を加工せず、そのまま各ページの表示に使用しています。
透明なリンク領域を画像に重ねているため、元のデザインの見た目は変わりません。

■ 機能
- 全ページ共通の上部ナビゲーション
- トップ画面下部の4カードから各ページへ遷移
- 電話番号は tel: リンク
- お問い合わせボタンからフォームへ遷移
- 施工事例6件の詳細ダイアログ（閉じるボタン、背景クリック、Escキー対応）
- 採用職種を選んで問い合わせページへ遷移
- 会社案内の地図からGoogleマップ検索
- お問い合わせフォームの必須項目・メール形式のブラウザ検証

■ 運用前に必要な設定
- 会社住所の「群馬県みどり市〇〇町〇〇〇-00」は画像上の仮表記なので、正しい住所に差し替えてください。
- 電話番号 0120-123-456 と代表者名などが実情報か確認してください。
- お問い合わせフォームは現時点ではフロントエンドのみで、入力データは送信されません。公開前にメール/CRM等の送信先を接続してください。
- 施工事例の説明文はPNG内の見出しをもとにした紹介文です。実物件の情報に合わせて必要に応じて修正してください。

※「なお」フォルダ内に含まれていたケーキ店用の長いPNG2枚は、NAGOMIサイトの5画面とは別デザインのため、このサイトには混在させていません。


■ レスポンシブ表示
- PC（幅761px以上）は従来のPNGデザインと透明リンク領域を維持します。
- スマートフォン（幅760px以下）は、読みやすい縦並びレイアウトと開閉式ナビゲーションに切り替わります。
- 元の5枚のPNGは加工せず保持し、スマートフォン用の切り抜き画像を追加しています。
